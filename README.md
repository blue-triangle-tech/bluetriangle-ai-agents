**Slack Bot Installation Steps**

1. **Open the Slack Installation Link**  
   Open the following link in your browser:  
   [https://adk.bluetriangle.com/slack/install](https://adk.bluetriangle.com/slack/install)
2. **Select Your Slack Workspace**  
   Choose the Slack workspace where you want to install the bot.
3. **Authorize the Application**  
   Review the permissions requested by the application and click **Allow / Authorize** to continue.
4. **Complete OAuth Authentication**  
   The installation uses Slack’s **OAuth authentication**. You will be redirected through Slack’s authorization flow to securely authenticate and grant the required permissions.
5. **Installation Completed**  
   Once authorization is successful, the Slack bot will be installed in your selected workspace.
6. **Available to Workspace Users**  
   After installation, the bot will be available for users across the workspace according to the permissions and configuration provided during installation.

**Note:** The installation needs to be performed for each Slack workspace where the bot is required. The person performing the installation must have the necessary permissions in that workspace to install applications.

**Microsoft Teams Bot Installation Steps**

1. **Sign in to Microsoft Teams**  
   In the Teams desktop app or web version, sign in using the **Microsoft 365 account associated with the target tenant**.
2. **Open Manage Your Apps**  
   Go to **Apps → Manage your apps → Upload an app**.
3. **Upload the Bot Package**  
   Select **Upload a custom app**, choose the provided ZIP package, and click **Add**.  
   **Bot Package / Repository:**  
   [https://github.com/blue-triangle-tech/bluetriangle-ai-agents](https://github.com/blue-triangle-tech/bluetriangle-ai-agents)
4. **Select the Installation Destination**  
   Choose where you want to make the bot available:
   - **Open** — For personal use and one-on-one bot conversations.
   - **Select a team or chat** — To make the bot available within a shared team or chat.
5. **Verify the Installation**  
   Once the bot is installed, send it a message to confirm that it has been successfully installed and is responding as expected.
